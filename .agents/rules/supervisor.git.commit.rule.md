# Rule: Idioma de Mensagens de Commit do Git dos Supervisores

## 1. Idioma Padrão Obrigatório (Português PT-BR)
- Todas as mensagens de commit de Git criadas pelos Supervisores Locais nos projetos DEVEM ser escritas em **Português (PT-BR)** por padrão.
- As mensagens devem ser claras, diretas e descritivas (ex: `feat: adiciona componente de tabela de sensores`, `fix: corrige rota de ingestão de telemetria`).

## 2. Exceção por Instrução Explícita
- O uso de Inglês ou outro idioma nos commits APENAS será permitido se o João ditar instrução explícita em contrário para aquele repositório específico.
